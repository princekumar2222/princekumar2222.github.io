# Prince Kumar Portfolio

## Files
- `index.html` — main portfolio page
- `style.css` — design and responsive layout
- `profile.jpeg` — uploaded profile photo

## Run
Open `index.html` in a browser.

## Before publishing
Replace the placeholder LinkedIn, GitHub and LeetCode URLs in `index.html`
with your real profile URLs.

For Google visibility, publish this site publicly and keep the same name,
university and specialization across your public profiles.
