PRINCE KUMAR PORTFOLIO

Files:
- index.html
- style.css

HOW TO USE:
1. Replace the current index.html and style.css in your GitHub Pages repository with these files.
2. Add your LinkedIn profile photo to the same folder and name it exactly: profile.jpeg
   The page uses profile.jpeg but cannot automatically fetch your LinkedIn profile picture.
3. If your current repository already has profile.jpeg, replace it with the LinkedIn photo.
4. Google Analytics measurement ID G-G8SBYF4QBN is kept once in index.html.
5. The Projects section has been completely removed. The View Projects button has also been removed.
6. Search-engine improvements are included, but Google ranking or a specific position cannot be guaranteed.

NOTE:
The university-name button copies "GLA University" when clicked. For clipboard access, use the site over HTTPS (GitHub Pages does this).
